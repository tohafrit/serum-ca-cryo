# serum-ca-cryo

Computational backbone for an InnoCentive submission:
**"Preventing post-thaw decrease in calcium concentration in serum-based QC standards"**

---

## Three headline numbers

| Result | Value | Figure |
|--------|-------|--------|
| Predicted Ca deficit at 6 months (standard thaw) | **5.4%** — matches Seeker's ≥4% threshold | fig05 |
| Vials exceeding 4% threshold at 6 months | **42%** — matches Seeker's "in some samples" | fig06 |
| Combined+ protocol at 12 months | **0.0%** vials >4%, achieved in 90 min vs Seeker's 48-h workaround | fig09 |

The model independently validates the Seeker's 48-h cold equilibration workaround (predicted
<1% deficit): 2880 minutes gives 28× more dissolution time than a 60-minute standard thaw.

## Mechanism (textual schematic)

```
FREEZING
  → cryoconcentration (k=5.58 for glycerol 15%): [Ca] 2.75→15.4 mM, [Pi] 1.8→10.1 mM
  → ion product ×31 vs physiological; SI(HAp) rises from +5.1 to +7.5
  → CO₂ outgassing raises local pH from 7.4 to 7.8–8.8

NUCLEATION (stochastic; glass surface-catalysed)
  → ACP precipitates on glass heterogeneities
  → nucleation delay ~ Gamma(shape=3, scale=30 days) per vial
  → explains vial-to-vial variability (Sobol ST = 0.71, dominant parameter)

STORAGE AT −20°C (6–12+ months)
  → Ostwald ripening: ACP → OCP → HAp
  → HAp microcrystals grow to r ≈ 200–500 nm by 6 months
  → HAp dissolution kinetics: t½ ≈ 2–8 h in standard thaw conditions

THAW (standard: 22°C, 60 min)
  → ACP dissolves in minutes: no deficit at <3 months
  → HAp: only ~35% dissolves in 60 min at 6 months → 5.4% deficit

THAW (Seeker workaround: 2–8°C, 48 h)
  → D(Ca²⁺) at 4°C ≈ 60% of 22°C, but 48 h = 2880 min (48× more time)
  → Net λ×t increases ~28× → >88% HAp dissolves → <1% deficit
```

Three observations explained by one mechanism:

- **6-month threshold**: Ostwald ripening produces slowly-dissolving HAp only after ~3–6 months
- **Reversibility**: HAp is thermodynamically metastable at physiological ionic strength; no irreversible chemistry
- **Vial-to-vial variability**: Stochastic nucleation delay is the dominant parameter (Sobol ST = 0.71)

## Repository structure

```
src/
  freezing_trajectory.py   Module 2: cryoconcentration & pH trajectory
  saturation_indices.py    Module 3: SI for 8 mineral phases with albumin binding
  supersaturation_map.py   Module 4: SI heatmap over k × pH grid
  ripening_kinetics.py     Module 5: ACP→OCP→HAp Ostwald ripening + Noyes-Whitney
  vial_simulation.py       Module 6: Monte Carlo (10,000 vials, 50 batches)
  interventions.py         Module 7: 10 intervention scenarios
  phreeqc_runner.py        Module 8: Davies vs WATEQ thermodynamic cross-check
  plot_fig*.py             Figure generators

tests/                     139 tests, 8 modules
data/                      6 CSV tables (auto-generated by make figures)
figures/                   11 figures + 4 supplementary (auto-generated)
phreeqc/                   WATEQ parameter database (documentation)
```

## Reproduce all figures

```bash
git clone https://github.com/tohafrit/serum-ca-cryo
cd serum-ca-cryo
make all          # installs deps, runs 139 tests, generates 11 figures
                  # < 2 minutes on Apple Silicon (after deps cached)
```

Individual targets: `make setup`, `make test`, `make figures`, `make clean`.
